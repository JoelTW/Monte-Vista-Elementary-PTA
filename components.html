Event card (event-card) and event list (upcoming-events)

Event cards are made from files in the _events folder (one file per event). To show the next few events anywhere:

{% include upcoming-events.html limit=2 %}
{% raw %}{% include upcoming-events.html limit=3 %}{% endraw %}
{% raw %}{% include upcoming-events.html grouped=true %}{% endraw %}

limit = how many to show. grouped=true adds a month heading. Events dated before today are left out automatically when the site rebuilds.
